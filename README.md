# 数学建模 Skills

本仓库收录安装到 Codex 的数学建模工作流，以及论文模板、绘图脚本和 Typst 离线文档。

## 目录

- `skills/1start-mathmodel`：工作流入口。
- `skills/2analysis-modeling`：赛题分析与模型设计。
- `skills/3coding-visual`：编程求解与数据图表。
- `skills/4drawio`：流程图与模型结构图。
- `skills/5writing`：论文写作，含 34 套 Typst/LaTeX 模板。
- `skills/6verity`：结果与论文验收。
- `skills/doctor`：依赖检查与安装向导。
- `skills/mathmodel-figure-templates`：科研绘图模板。
- `skills/typst-author`：Typst 写作与离线参考文档。
- `skills/_references`：共享数学建模规范。

将需要的 Skill 文件夹放入 Codex 的个人 Skills 目录，保留子目录结构。工作流各阶段共同使用 `_references`。论文模板的章节文件位于各模板的 `sections/` 目录。

这些资源来自用户提供的附件。运行绘图、编译论文和导出流程图需要相应的 Python、排版引擎或 DrawIO 依赖；安装 Skill 本身不安装这些程序。
