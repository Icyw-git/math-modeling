# C题第三问：预报更新与逐次购电调整的数学模型

## 1. 为什么这样建模

本赛题共4个顶层子问题，本报告只展开第三问。依据为本地`CUMCM2026Problems/C题/C题.pdf`第2页问题3、第2—3页附录，以及既有附件审计、第二问建模与实现。本文是数学建模交付，不是全年求解结果；未生成result3.xlsx，也不扩展第四问。

第三问不只是“更换光伏预测器”：新预报改变未来供需判断，合同调整改变实际供电和费用，储能又把不同时段的决策连接起来。因此采用：

> 历史负载预测＋已发布光伏预报 → 0时购电计划 → 6/12/18时合同调整 → 10分钟实际储能补偿 → 费用与状态反馈。

依赖第二问的历史选模、因果执行和约束校验，但新增预报版本、逐次合同账单及更新时刻对照。目标是满足负载并减少实际总购电费用，不是单独最小化预测误差；不预设第三问一定比已有第二问算法便宜。

## 2. 假设敏感性预检

### 2.1 模糊表述及解释

| 项目 | 主模型工作解释 | 对照或限制 |
| --- | --- | --- |
| 下调购电 | 退取消电量原价，再收50%违约费 | 不退款、另收50%罚费作为对照A |
| 多次调整 | 每次相对上一有效合同逐笔结算 | 不采用相对0时计划的最终净额一次结算 |
| 交易时刻价格 | 被修改电量交付时段的附件1电价 | 不用6/12/18时的即时价统一计费 |
| 功率时标 | 右端标签代表此前10分钟区间平均功率 | 这是离散化假设，不声称题面明确规定 |
| 效率 | 充、放电单向各0.9 | 往返效率0.9为敏感性解释 |
| 过剩电量 | 可免费弃用，无售电收益 | 未利用量不一定全是不可避免弃光 |
| 实时补偿 | 当前区间可快速测量和响应 | 不可提前读取下一区间实测 |
| 紧急供电 | 无题面以外的容量限制，只补负载缺口 | 不主动用5倍价格电量充电 |

前三项是用户确认的数学工作口径，不是附件新增的官方解释。即使取消的是先前按1.5倍价格增加的电量，也按本次取消量退1倍交付电价并罚0.5倍；不按历史交易批次退款，否则须换用带批次库存的另一种模型。

### 2.2 快速验算与递进性检查

10分钟最大交流侧充/放电量为5000/6=833.333333 kWh；可用容量为10800−1200=9600 kWh。单向效率各0.9对应往返效率0.81。

主口径下取消部分合同可降低沉没在过量采购上的费用，新增合同可替代5倍应急电；但新增合同仍可能因预测错误而浪费。不开启调整始终是合法选择。更多可选信息扩大理论策略集合，但具体近似算法的实际表现不保证单调改善。

不退款对照下，若减少合同只增加罚费，且多余电可免费弃用，那么保留合同通常支配主动下调。应报告这一机制，不能为使第三问“显得有用”而篡改约束。

### 2.3 最终采用的解释

主模型使用退款口径B、逐次增量结算、交付时段电价；其余物理参数延续第二问。首版使用固定线性日末延续价值，不强制每天回到6000 kWh，不把延续价值记为真实电费。所有收益比较统一初始状态和终端处理。

### 2.4 绘制的图像和对比表格

后续结果阶段展示逐次账单核验表、预测发布时间—有效时刻示意、典型日合同版本和SOC曲线、更新组合费用分解。此轮只给数学定义和表格设计，不制作结果图。

### 3.2 信息集合与观测顺序

记Iₖ为发布边界τₖ的信息：已完成日历史、当天t<τₖ的实测、边界实际SOC、既有合同/交易台账、已知日内价格，以及当前策略允许使用且已经发布的预报。当段和未来实测不在Iₖ中。

一个边界的顺序是：完成前一段并读取SOC → 接收当次允许的预报 → 优化并生效未来合同 → 当前段内测量供需并快速补偿 → 记录段末SOC和费用。储能控制的信息可包括当前段供需，但普通合同不得因提前看到当前段平均真值而被修改。

0时负载预测复用第二问过去28个已结束日的候选评分；候选包括上周、前两周、近期同星期中位数及周基线偏差修正，保持原函数的历史限制。首版当天各次更新固定0时负载点预测，只更新已发生误差信息和光伏预报，便于辨认新增PV信息的作用。

### 3.3 小时预报转换与误差档案

在发布时刻hₖ，取最新已完成区间PV代表值为锚点fₖ,₀，之后连接附件3的fₖ,₁,…,fₖ,₂₄。对目标右端点hₖ+(j+θ)小时，j为整数、0≤θ≤1：

\[
\widehat P^{PV}_{k}(j+\theta)
=\max\{0,(1-\theta)f_{k,j}+\theta f_{k,j+1}\},
\qquad \widehat V_{k,t}=\Delta\widehat P^{PV}_{k}((t+1)\Delta-h_k).
\]

后一式中hₖ以当天小时计，(t+1)Δ−hₖ是区间右端距发布时间的小时数，不能把区间编号误作小时。这里是“右端代表值×Δ”的离散近似，不同时宣称使用了梯形积分。首日0时无历史锚点时取首个小时预测值，并标记冷启动；其后午夜使用前一天最后一条已观测值。线性插值与逐小时保持作为离散化敏感性对照。

历史残差必须用当时真实可生成的预测定义：e^L=L−Lhat、e^V=V−Vhat，单位均为kWh。按相同发布时间提取过去28个完整已结束日的成组负载/PV残差，日期成对、整段保留，并以实际已验证目标为准；跨日目标未发生前不进入训练。

首版每个发布时刻采用至多28条等权历史日路径，不独立打乱时段，也不把四次不同版本误差混合。场景为Lω=max(0,Lhat+eLω)、Vω=max(0,Vhat+eVω)。历史不足时使用可得日期；完全没有残差时用零残差单场景并标明不具备不确定性校准。这一经验分布不等同于真实条件分布；后续可只利用已完成观测进行权重更新。

## 4. 每个费用项如何产生

### 4.1 符号与合同版本

| 符号 | 含义与单位 |
| --- | --- |
| πt | 第t交付时段固定价格，元/kWh，现有数据严格为正 |
| q⁰t | 0时普通购电计划，kWh |
| qᵏt | 第k次发布边界处理后的有效合同，kWh |
| ukt、vkt | 相对上一有效版本的增加、取消电量，kWh |
| at | 第t段交付前最后生效的普通合同电量，kWh |
| Lt、Vt | 当段实际负载、PV电量，kWh |
| ct、dt、rt、st | 交流侧充电、放电、应急购电、未利用电量，kWh |
| Et | 区间起始储能，kWh |
| pω | 场景概率，非负且和为1 |
| Φ(E) | 预测窗口外的成本延续近似，元，不是实际账单 |

在启用的发布边界k=1,2,3，对t≥τₖ：

\[
q_t^k=q_t^{k-1}+u_{k,t}-v_{k,t}\ge0,\quad
u_{k,t}=(q_t^k-q_t^{k-1})_+,\quad
v_{k,t}=(q_t^{k-1}-q_t^k)_+.
\]

其他时段和未启用边界保持合同不变，增减均为0。设k(t)为交付开始前最后处理的边界，则at=q_t^{k(t)}。u、v表示版本变化，不是“调整后的购电总量”。

### 4.2 逐笔账单及等价形式

主模型的真实费用：

\[
C_B=\sum_t\pi_tq_t^0
+\sum_{k=1}^3\sum_{t\ge\tau_k}\pi_t(1.5u_{k,t}-0.5v_{k,t})
+\sum_t5\pi_t r_t.
\]

取消v的账单为−πv+0.5πv=−0.5πv。即使当前调整账单为负，也不能将其当作售电收入。历史已付/已退账单在滚动优化中是常数，但在最终费用汇总中必须完整保留。

定义Ut=Σk ukt、Wt=Σk vkt。由于at=q⁰t+Ut−Wt，有如下独立校验恒等式：

\[
C_B=\sum_t\pi_t\left[a_t+\tfrac12(U_t+W_t)\right]+\sum_t5\pi_t r_t.
\]

这揭示了模型含义：最终普通供电按原价计算，合同每变化1 kWh另承担半价摩擦成本。增量和减量抵消不了交易摩擦。非负合同、正价格下普通费用不会靠反复交易变成负数。

不退款对照：

\[
C_A=\sum_t\pi_tq_t^0+\sum_{k,t}\pi_t(1.5u_{k,t}+0.5v_{k,t})+\sum_t5\pi_t r_t.
\]

为比较工作假设的实际影响，A、B应分别优化各自策略；对同一策略重新算账只衡量计价差，不是两种模型的最优策略差。

### 4.3 手工账单验算

令交付单价π=1，不计应急：

| 合同版本/kWh | 主模型B/元 | 不退款A/元 |
| --- | ---: | ---: |
| 100，不变 | 100 | 100 |
| 100→120 | 130 | 130 |
| 100→80 | 90 | 110 |
| 100→120→80 | 110 | 150 |
| 100→80→120 | 150 | 170 |
| 100→120→100 | 120 | 140 |
| 100→0 | 50 | 150 |

例如100→120→80，最终供电80度，总变动60度，费用为80+0.5×60=110元，不能按最终相对0时减少20度算成90元。增加1度应急电再加5元。

在正价下，固定qᵏ−qᵏ⁻¹时若u、v同时为正，同时减少二者ε会使主目标下降πε。因此在当前线性目标中，以u,v≥0及版本等式即可在最优解处获得互斥；导出账单仍用版本差的正负部重算。此结论不推广到负价或额外奖励规则。

## 5. 储能与物理可行性

对所有实际区间或优化场景：

\[
a_t+r_t+V_t+d_t=L_t+c_t+s_t,
\qquad E_{t+1}=E_t+0.9c_t-d_t/0.9,
\]
\[
1200\le E_t\le10800,\quad
0\le c_t,d_t\le M=5000/6,\quad c_td_t=0.
\]

购电、充放电、应急及未利用量均非负。MILP用z∈{0,1}表示充电模式：c≤Mz、d≤M(1−z)。另加r≤L(1−z)，使应急电与充电互斥；L为该区间或场景的已给定非负负载电量，不是任意大常数。因为无应急充电、供给均非负，补负载所需r不超过L，该上界不排除必要补偿。

对实际控制可直接采用更清晰的构造。令b=a+V−L：

\[
0\le c\le\min\{M,(10800-E)/0.9,\max(b,0)\},
\quad 0\le d\le\min\{M,0.9(E-1200)\},\quad cd=0,
\]
\[
r=\max(-b+c-d,0),\qquad s=\max(b-c+d,0).
\]

该构造禁止应急充电、禁止应急与弃用同时发生，并严格满足平衡。MILP中若出现r、s同时为正，可同时减少而不改变SOC，使正价应急费用下降，因而在最优解中不应发生；数值解须独立复核。

可行兜底为保持普通合同、电池停机c=d=0、r=max(L−V−a,0)、s=max(a+V−L,0)。其可行性依赖初始SOC有效、应急无限容量和允许弃用。它不保证满足另行施加的硬终端目标；硬目标下需额外检查可达性。

2025年1月1日初值6000 kWh，逐日连续传递。首版各消融共用第二问的一月预热轨迹，2月1日初值1200 kWh；这是为隔离正式期策略差异的统一实验初始化，不是假装第三问已独立运行了一月。正式期末统一取1200 kWh作为比较边界，并明确其是实验约束、不是题面要求。其他起始/终端方案只能成组替换。

## 6. 如何利用新预报：理论目标与滚动近似

### 6.1 理论因果策略模型

策略μ包含合同调整规则和实时储能规则，前者对发布时刻信息Iₖ可测，后者对当段已允许观测的信息可测。理论目标：

\[
\min_{\mu\text{因果可行}}\mathbb E[C_B+\Phi(E_T)\mid I_0].
\]

严格多阶段场景树中，两个场景若在某决策时刻有相同已观测历史，则相应合同和控制决策必须相同；当前需求尚未观测时，不能通过场景编号识别其未来。储能动作可在当前需求观测后分叉，普通购电不得提前分叉。没有未来预报演化的概率模型时，不声称完整求解了这一理论目标。

### 6.2 可落地的合同滚动MILP

首版每次只优化至当天24时。设当前边界s=τₖ、实际储能e、上一合同b_t=q_t^{k-1}，Ωₖ为该时刻历史残差场景集。合同a_t在所有场景间共享；各场景具有独立的充放电、应急与SOC变量，并满足第5节约束，E_{s,ω}=e。

0时求：

\[
\min\ \sum_{t=0}^{143}\pi_ta_t+
\sum_\omega p_\omega\left[\sum_{t=0}^{143}5\pi_t r_{t,\omega}+\Phi(E_{144,\omega})\right].
\]

6/12/18时求：

\[
\min\ \sum_{t=s}^{143}\pi_t(1.5u_t-0.5v_t)+
\sum_\omega p_\omega\left[\sum_{t=s}^{143}5\pi_t r_{t,\omega}+\Phi(E_{144,\omega})\right],
\quad a_t=b_t+u_t-v_t\ge0.
\]

过去账单为常数，不进入上述当前优化目标；不能把上一合同原价再收一次。当前MILP不预先模拟尚未发布的未来6/12/18时预报，也不预设未来合同修改，暂将本次有效合同冻结到日末估价；实际到下一个允许边界再重新求解。这是可实现的滚动近似，不包含“等待下一次调整的最优期权价值”。

场景内独立储能补救可提前识别整条未来路径，因而对固定本次合同的补救成本偏乐观。该模型返回的优化目标不是实际账单，也不能无条件称为第三问完整理论问题的下界，因为它同时冻结了未来交易、并使用近似终端价值。

固定线性终端值沿用第二问：

\[
\Phi(E)=-\lambda(E-1200),\qquad
\lambda=\min_t\pi_t/0.9=0.4125555556\text{元/kWh}.
\]

λ只是延续成本斜率近似，不是已证明正确的储能影子价格。敏感性预设λ倍率0、0.5、1、2；不因全测试期费用最低而倒选参数冒充在线策略。12月31日改为终端1200的硬边界、不额外结算Φ。首版不使用跨日预报来更改固定Φ，所以不能声称已利用其次日信息；该部分留作终端价值增强研究，也不得提前执行次日合同。

### 6.3 10分钟实时执行与反馈

在当前有效合同和预测分布下，构造SOC共同延续值函数，不按“已知未来场景路径”执行储能。近似Bellman递推：

\[
W_t(E)=\sum_\omega p_\omega\min_{(c,d)\in A(E,b_{t,\omega})}
\{5\pi_t r_{t,\omega}+W_{t+1}(E')\},\qquad W_{144}=\Phi.
\]

集合A为第5节的无应急充电可行集合。先对当段观测作响应、再对未观测未来取共同延续值，区别于每条未来路径各自最优执行。用场景边缘分布递推仍忽略部分跨时相关性，不称为严格历史状态Bellman最优。

实际执行时，将当段真实b代入同一可行集合，选择使5πr+W_{t+1}(E')最小的动作，只执行一段；同价最优时选储能变化绝对值较小的动作。首版沿用第二问193点SOC网格（50 kWh），对实际连续SOC用分段线性插值，并加入连续可行区间端点及不充不放候选，防止粗网格制造不必要应急电。97点与193点作为后续稳定性对照。

每个启用边界更换允许预报，重新生成场景、合同及价值函数；未启用预报不得被读取。为了信息实验可比，0/6/12/18仍是各组共同的计算边界，但无新预报组只能使用其合法旧版本；普通合同只在各组允许的调整边界更改。

### 6.4 求解规模、停止与失败规则

单次合同模型至多144段、28条场景，物理变量与约束规模O(144×28)，包含场景充放电二进制变量，因此不是多项式时间保证。沿用HiGHS，建议单线程、固定种子0、每次60秒、相对gap阈值0.001；求解状态、可行解和实际gap必须记录，不用“Optimal”宣称全年最优。

193点控制网格朴素递推规模O(H×|Ω|×193²)，H为剩余段数；属后续需要测时和向量化的工作，本轮不承诺全年耗时。

求解限时但存在回代合格的可行解则使用并报告gap；无可行解时0时采用非负预测净缺口购电，日内保留上一合同，实时使用物理兜底。原始数据缺失、错位、非有限或SOC无效须停止，不能用兜底掩盖输入错误。硬年末目标须先裁剪不可达动作；若只能回退到不满足年末条件的可行供电，则标记验收失败，不能报告为成功策略。

## 7. 怎样判断更新是否值得

### 7.1 信息收益与合同调整收益分开

对S⊆{6,12,18}的全部8个集合建立配对策略：

- F(S)：0时制定普通合同，之后冻结；允许S中的预报更新储能判断。
- A(S)：使用与F(S)相同的预报规则，并允许在S中逐次修改合同。

首版两组共享同一0时算法与参数。对固定S，各正式期日初由各自上一日实际SOC连续传递，不强迫每日相同；正式期第一天初始SOC及最后一天终端边界一致。S为空时F与A应完全一致。

\[
G_{\rm info}(S)=C_F(\varnothing)-C_F(S),\quad
G_{\rm adjust}(S)=C_F(S)-C_A(S),
\]
\[
G_{\rm total}(S)=G_{\rm info}(S)+G_{\rm adjust}(S).
\]

这是一条受控算法比较的费用分解，不是唯一的因果归因。全年策略可反复观测但必须固定各组允许的时刻，不能事后逐日挑选最便宜组合。

### 7.2 判据与解释边界

记录计划费、上调支出、退款、下调违约费、应急费及真实总费，同时报告增减电量、应急量/频次、未利用量和SOC。调整净费用为负并不意味着全年总费用为负。

已有附件核验显示，6时和12时更新对当日后续整点的误差有明显改善，因此优先提出其可能有经济价值的假说；但新增合同1.5倍价和取消摩擦可能抵消收益。18时对19—24时整点PV作用很小，不代表18:10—18:50必定无PV。固定终端首版不能评价次日预报改善跨日储备的额外价值。

最终使用真实费用差判断“对该数据和策略是否值得”，并可按7天连续块、固定种子0、1000次配对Bootstrap描述差值不确定性；保留季节非平稳和仅一年度样本的限制。误差降低不是费用下降，样本内组合排名不是保证未来收益。

### 8.2 数学与程序验收设计

1. 账单覆盖第4节所有序列，并检查有应急电时加5πr；连续往返修改成本应为正，不能净额抵消。用独立恒等式核对总费。
2. 将未来实际值或尚未发布预报任意改变，已有合同与动作不变；只改变当段观测可以改变当前储能动作，不能改变已冻结普通合同。
3. 检查6时边界只改t≥36；禁用的预报版本不能进入插值、残差校准、控制或终端值；午夜使用前一日最后已完成记录。
4. 验证下限SOC无法再放、上限无法再充、833.333333 kWh段功率限制、连续阴天、PV富余和最大负载缺口；实际平衡与SOC残差容差1e-6 kWh。
5. 紧急电与充电不得同时为正；互斥、合同非负和版本冻结误差不超过1e-6 kWh。对只因数值容差产生的小负数先记录，再在显示层处理，不用裁剪掩盖不可行解。
6. 一月预热与正式期衔接、年末可达性和跨日连续性单独检查；终端价值不纳入真实账单，初末不同的策略不直接比较。
7. 正价条件下校验u/v互斥的经济论证；对不退款模型分别优化，不能将主策略换算费用冒充对照最优值。
8. F(空集)=A(空集)，总收益=信息收益＋调整收益；更多信息的近似策略可能更差，不把反例当作自动的数据错误。

## 9. 本轮完成状态与结论

已完成第三问的费用推导、合同版本定义、信息时序、供需/SOC模型、可实施滚动近似、更新价值分解和验收设计，并同步修订总报告的主费用假设。7个手工合同序列的两种账单均通过计算核对；1000个固定种子0的非负随机合同序列通过“最终合同＋半价总变差”恒等式检查，误差小于1e-9元。这些随机序列仅用于代数测试，不是赛题数据或优化实验。本轮没有运行第三问优化或声称得到节省比例。

核心判断是：**用最新预报评估“调整合同与储能补偿哪个更便宜”，而不是把最新预测净缺口直接当购电计划。** 逐次修改有摩擦，储能有跨时价值，应急电有5倍代价；三者必须在同一费用与物理框架内权衡。
