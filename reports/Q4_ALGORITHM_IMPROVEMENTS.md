# 第四问算法改进：证明、实现与分阶段验证

## 1. 等价消除充放电循环

沿用区间电量单位，单向效率均为η=0.9。对于c、d同时为正的区间，取δ=min(c,d/η²)，令c'=c−δ、d'=d−η²δ、s'=s+(1−η²)δ。

SOC增量不变：ηc'−d'/η=ηc−d/η。供需平衡中d−c−s不变。新充放电量均非负，且至少一项为零；两项只减不增，原功率上界继续成立。普通合同、应急电量和SOC不变，因而场景账单、均值、CVaR及终端估值均不变。

证明依赖免费且无上界的弃用、无循环吞吐成本及现行效率模型；若增加弃用惩罚、吞吐计费或限制弃用来源，须重新论证。这里证明的是物理调度变换，不要求变换后保留松弛模式变量z的旧值；最终按真实物理约束回代。

它仅消除c/d循环。若变换后c'>0且应急r>0，仍违反禁止应急充电，必须重新优化。不能把整个原模型直接宣称为等价LP。12个定点窗口每个消除了50—128处循环，但仍有6—60处充电/应急冲突，最终都需固定模式修复，结果与单模式基线相同。

## 2. 多模式候选与择优接口

连续松弛并循环消除后，固定无冲突区间的充放电模式，对剩余充电/应急冲突生成最多5套模式：偏充电、偏应急、按c≥r、c≥5r和5c≥r选择。1与5是本轮预先固定的候选阈值；5虽与应急倍率相同，此处只是候选启发式，不是解析最优阈值。重复模式去重，每套模式重新解LP、回代，并仅保留更低重建目标。

该首版是有限候选搜索，尚未实现逐变量局部翻转、基于对偶量的邻域筛选或跨窗口模式热启动；不把这些后续方案描述成已完成。

30秒名义预算最多35%分给松弛，剩余时间在尚未尝试的候选间分配。固定模式LP的最优不能证明完整问题最优；仅当原松弛达到最优时保存有效下界，并补齐终端常数偏移。实际费用与求解目标分开记录。

组合接口仍先调用原求解器。原解回退，或未证明最优且gap未知/大于0.001时，尝试多模式修复。已有合格原解时仅接受目标严格下降的候选。因此单窗择优不丢弃好解，但跨窗口实际费用仍可能因未来误差和SOC变化变差。

12窗口测试中，原4个回退均获得候选；8个双方可比窗口中6个目标改善、2个更差，总候选耗时45.71秒。组合接口拒绝较差候选。该耗时只计候选算法，不能当作先调用原求解器后的组合总耗时。多模式15项测试、组合路由5项测试已通过。

实现与定点数据：code/q4_solver_cycle.py、code/q4_solver_multimode.py、code/q4_solver_adaptive.py；results/q4_cycle/、results/q4_multimode/。

## 3. 四季连续验证设计

在运行前固定冬季2月1—7日、春季5月15—21日、夏季8月15—21日、秋季11月15—21日。四种策略各跑四个窗口，共16组，每组1008个区间。冬季属于此前已观察的开发窗口，其余三季提供额外验证；这不是完全未见过的独立测试集。

每个新策略从对应原年度策略在该周起点的SOC开始，历史预测仍只使用当时以前数据。四种策略各自与自己的原版本比较，不能将不同初始SOC的跨策略季节总费直接用作公平排名。每周内部SOC连续，但四个季节彼此不连续，因此不是一年连续回测。

期末不强制SOC相等。同时报告费用差、期末SOC差和统一预测参考价下的估值调整差。估值调整不属于账单，也不保证是真实储能延续价值。应急电量、未利用电量、回退、窗口耗时和候选接受率同时考察。

原始结果在results/q4_adaptive_seasons/，汇总与全年验证判断见Q4_SEASONAL_VALIDATION.md。

## 4. 后续阶段的条件

四季结果通过物理、账单和因果性检查后，根据是否跨季节稳定改善决定全年验证是否值得开展。即使有收益，也不能保证全年CVaR下降。

Benders分解和动态风险控制属于后续研究。普通Benders的LP对偶割只能用于连续补救模型；禁止应急充电的非凸性尚未完全消除，不能直接把固定模式子问题的割当作完整问题的有效全局割。场景扩充、价值函数改进和嵌套风险会改变近似或风险目标，应各做消融验证，不能一次混入当前对照。
