## 2. 数据核验与预测模型选择

- 附件1有144段电价、负载、光伏数据；附件2与附件4各覆盖365天、每天144段；附件3有1460次发布、每次24小时预报。核心数值字段无缺失或非有限值。
- 附件2全年共有330天出现至少一个光伏高于负载的时段；附件4价格范围为0.0076—1.7936元/kWh，没有零价或负价。储能模型必须同时表达光伏消纳和分时购电。
- 附件1与全年同一时段平均轮廓高度接近，不能把其负载/PV轮廓冒充只用历史数据训练得到的预测。

以2月1日—12月31日的48096个10分钟时段评估，每个预测只使用此前日期的数据；这些是简单基线的样本外误差，不是经独立测试集确认的最终预测器。

因此，问题2先采用“周周期负载＋近期光伏”的可解释基线，再比较残差回归或树模型；问题4先采用周周期价格基线。复杂模型是否有收益，须通过按时间滚动验证和实际购电结算判断，不能只比较训练拟合度。后续调参与选模必须限定在当时已经发生的历史窗口。

对问题3，比较同一天同一目标整点，而非不同发布时间各自未来24小时的混合指标：6时更新对7—12时的MAE从361.54降至156.60 kW；12时更新对13—18时从382.36降至70.39 kW，每组2004个配对样本。18时更新对19—24时整点的绝对改善极小，但18:10—18:50仍可能有光伏，且次日预报影响跨日SOC，不能直接判定18时更新无用。

整点预测与10分钟调度的插值仍需明确假设并做敏感性分析；本次预报评价仅在可直接匹配的整点进行，不把插值值当成原始预报。

## 3. 第一问模型及试算口径

采用144个10分钟区间，原始时标00:10—次日00:00暂解释为此前区间的平均功率标签，电量为功率除以6。购电量q、交流侧充电量c、放电量d和未利用电量s非负，单位均为kWh。

目标为最小化Σπq；每段满足：

```text
q[t] + PV[t] + d[t] = Load[t] + c[t] + s[t]
E[t+1] = E[t] + 0.9*c[t] - d[t]/0.9
1200 <= E[t] <= 10800
0 <= c[t], d[t] <= 5000/6
c[t] <= (5000/6)*z[t]
d[t] <= (5000/6)*(1-z[t]), z[t]为0/1变量
E[0] = E[144] = 6000
```

没有卖电收益；允许未利用电量。主口径充、放电效率各90%，意味着往返效率81%。LP松弛去掉充放电互斥二进制约束，用于给出下界，不能据此一般性断言所有算例都无需互斥约束。

## 6. 正式结果前必须处理的边界

1. **时间映射**：附件5的result1首段是0:10—0:20，最后一段跨到次日0:10，其他模板也有类似标签问题，与全天00:00—24:00不一致。目前仅在派生CSV中采用连续144段，原模板未改。
2. **费用口径**：问题3下调是否退回原计划电费，模板没有消除歧义。主报告保留“原计划照付＋下调罚费”与“退回取消电量电费＋罚费”两种台账。前者在允许免费弃电时通常使主动下调缺乏经济动机，不能套用后者收益。
3. **可用信息**：问题2、4不得用当天实测未来负载/PV/价格制定0时计划；问题3只能用截至决策时已经发布的预测。完美信息最优值只能用作下界。
4. **跨日状态**：全年调度SOC连续传递，不能每日重置6000 kWh；问题1的日末闭环不直接套用于全年每一天。
5. **模板扩展**：附件5充放电、紧急购电中的日期和省略号是示例，不是输出行数上限。正式结果需覆盖2月1日—12月31日334天，并核对全天合计与费用。

## 8. 后续优先顺序

先固定时间、效率、取消购电和价格信息口径，再完成问题2的因果全年调度与费用台账；随后问题3比较0/6/12/18时更新的净经济收益；最后扩展问题4联合价格不确定性。CVaR作为风险敏感性扩展，不在没有样本外证据时增加复杂度。本轮用核验表和可追溯CSV表达证据，完整全年结果产生后再绘制SOC轨迹、费用构成、预测误差和更新收益图。
